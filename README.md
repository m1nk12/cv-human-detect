## PROJECT OVERVIEW
A small computer vision application that detect human in CCTV videos using opencv and ultralytics yolo model.
---
## Problem Statement
CCTV footage often comes in bad quality and requires manual review.

This project automates CCTV human detection by sampling video frames, preprocess frame, frame quality enhancement, human detection with yolo model and store frame in a warehouse.
